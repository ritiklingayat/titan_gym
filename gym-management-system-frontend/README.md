# Gym Management System Frontend

Premium React + Vite frontend for a Gym Management System.

## Features
- Modern responsive gym landing website
- Customer login/register/forgot password UI
- Customer dashboard
- Separate admin login at `/admin`
- Admin dashboard, members, payments, enquiries, trainers management
- Fee structure and membership plans
- Payment page UI
- Auto invoice page with print/download UI
- Free online gym images via Unsplash URLs

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Customize
- Update dummy data in `src/data/gymData.js`
- Replace fee structure values after checking your fee structure photo
- Replace invoice format after checking your bill photo
- Backend/API can be connected later in service files
